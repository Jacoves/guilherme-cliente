# Site Sou Mandi

Landing page estática preparada para publicação no GitHub Pages.

## Arquivos obrigatórios

- `index.html`
- `logo-mandi.jpeg`
- `foto-mandi.jpeg`

Os três arquivos devem permanecer na raiz do repositório para que os caminhos usados no HTML funcionem.

## Visualização local

Abra `index.html` diretamente no navegador ou execute um servidor HTTP simples nesta pasta.
